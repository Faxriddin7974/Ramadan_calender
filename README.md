#  Auto Insurance Management System

A comprehensive backend solution for automating the car insurance process. This project simplifies policy creation, database management, and premium calculations.

##  Key Features
* **Automated Policy Issuance:** Efficient logic for creating and managing insurance policies.
* **Database Integration:** Secure storage and retrieval of client data using SQL.
* **Web Interface:** User-friendly frontend built with HTML templates and static assets.
* **Cross-Platform Logic:** Includes core components in both Python and C++ for optimized performance.

##  Tech Stack
* **Backend:** Python (Flask/FastAPI style)
* **Logic:** C++ for core computational tasks
* **Database:** SQL
* **Frontend:** HTML, CSS (Static templates)

##  How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the application: `python app.py`
3. Access the dashboard via `localhost`.
